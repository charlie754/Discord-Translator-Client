# decision to ship one more third party the user's client can be pointed at —
# it is not housekeeping. Justify it in the PR that adds it.
#
# Removing code that reaches a host? Remove its line too, or the next audit
# reads a stale list as the current attack surface.
#

# `workbench.hover.delay` — as hostnames. That is ~491 entries the checker cannot
# tell apart from real hosts, and it is a scoping defect in checkHosts.mjs, not a
# reason to list them here. Its URL pass is unaffected and still authoritative;
# the four real hosts it found in that tree are listed below.
