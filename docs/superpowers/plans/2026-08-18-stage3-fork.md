# Stage 3 — Discord Translator client fork

**Date:** 2026-08-18
**Authority:** Operator: "totally rebrand it to Discord Translator, no more Equicord exist in it",
then "Yes — start the fork".
**Goal:** A standalone Discord client mod branded entirely as Discord Translator, installable in one
step into the user's real Discord, containing only the translator.

## The licence boundary — decided, not negotiable

GPL-3.0 §5 requires preserving copyright notices. **The 1,123 Vendicated headers stay.** Removing
them to erase the name is a licence violation, not a rebrand.

What changes and what does not:

- **User-visible: everything.** App name, window title, tray, settings section, About screen, data
  directory, asar name, update endpoint, installer. A user never encounters "Equicord".
- **Source headers: unchanged**, with our copyright added alongside and a dated §5(a) modification
  notice. Equicord follows this same discipline — their house rules keep the
  `Vencord, a Discord client mod` header even on files they wrote themselves.

## Import strategy — clean import, not a GitHub fork

A GitHub fork inherits Equicord's workflows, and their `build.yml` release-upload step is **not**
repo-guarded, so it would run against our repository. It also inherits an upstream relationship we
do not want for a divergent product.

Instead: a new empty repository, seeded with one commit that states its provenance
(`Imported from Equicord @ <sha>`). That satisfies GPL §5(a)'s "state that you changed it" without
dragging in someone else's CI.

## Standing hazards

1. **Updater self-poisoning.** `gitRemote` is baked from `git remote get-url origin` at build time.
   Build from a clone still pointing upstream and the binary replaces itself with Equicord.
2. **`DATA_DIR` collision** corrupts an existing Equicord install's settings.
3. **Inherited CI** — delete before first push, not after.
4. **Equilotl's rate-limit fallbacks** silently install upstream.
5. **Maintenance changes permanently**: ~0 today as a userplugin → **12–16 hrs/month** rebasing.

## Not doing

Code signing (operator declined): Windows users get SmartScreen, macOS users get Gatekeeper. Upstream
Equilotl is unsigned too, so this is parity, not a regression.
